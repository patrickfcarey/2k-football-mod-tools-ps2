# What cost us on 2026-09-06, and where each fix now lives

One day: fourteen module agents, two new game modules, three identity passes, two Blitz probes,
an efficiency review. Everything below is a thing that measurably slowed us or spent tokens for
nothing, with the fix and the place it is *enforced* rather than remembered. Ranked by cost.

## What the day also proved worth keeping

- **Fable on the one problem the last agent could not close.** The Blitz PAK locator, which blocked two discs at rung `unknown`, fell in the first scan on the strongest model after a full earlier pass had failed; the model rule (#1) is about choosing, not about never spending.
- **Killing an agent is cheap when its measurements are files.** The MVP disc index (40,423 rows, 62 s) and dump index (1,308 rows) outlived their agent; the replacement read them in a second.
- **The NAS loop.** 3 minutes for 5,600 tests against 40 minutes on the dev box; every gate today ran there.
