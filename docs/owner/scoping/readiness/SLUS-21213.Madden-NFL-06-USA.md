The caches parse with the module's own `containers.parse_preload_cache`, and 5,761 of 5,773 copies are byte-identical; 0 differ and 12 could not be resolved to a container on this disc.

An *unresolved* copy is one whose `DTLS` row names a member the container it names does not have, so the module's `PreloadCopy.length_in` refuses rather than guessing how long the copy is. The bytes at those offsets carry: TERF 9, BNKl 3.

Madden 09's control run: 2 cache(s), 6,270 copies, 6,268 identical.
