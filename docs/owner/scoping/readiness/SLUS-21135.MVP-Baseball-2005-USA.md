### Do the databases have Madden 09's schema?

No control was given, so no comparison was made. The tables this disc carries, with their field counts, are in the JSON's `schemas` block.

### The preload caches

**No `QL01` preload cache is on this disc.** Every writer's cache-coherence step — the one that keeps a container's cached directory copies in step with the container — has nothing to keep in step here, which removes work rather than adding it. Whether this engine year preloads through some other file is not established by this measurement.
